# Shadoword Brandkit Brainstorm

## Brand summary

**Brand:** Shadoword

**Category:** Developer-grade speech-to-text platform (desktop + daemon)

**Core purpose:** Make high-quality voice-to-text practical, private, and deployable across both local and API-first workflows.

**Primary promise:**
_“Control your voice pipeline from capture to transcript.”_

## Theme and positioning

- **Tone:** precise, calm, technical, trustworthy, founder-first
- **Design mood:** dark neutral UI system with restrained motion and a cool cyan accent
- **Emotional goal:** confidence and flow; users should feel they are in command, not at the mercy of an opaque cloud service.
- **Avoid:** over-the-top gradients, generic SaaS fluff, heavy stock photography, and feature shouting.

## App purpose unpacked

1. **Privacy-first transcription by default**
   - local inference path keeps raw audio off external infrastructure when desired
   - optional remote API is explicit rather than implicit

2. **Performance-aware voice tooling**
   - GPU/accelerator-aware model selection
   - clear runtime state and model lifecycle controls

3. **Workflow parity across interfaces**
   - desktop UX for live usage
   - daemon/API for automation and integration

## Symbol strategy

### Core metaphor

A **voice waveform becoming structured text**: silence, wave, and clarity.

### Logo idea

Existing mark + mark family can be amplified through:

- subtle signal-line motifs
- clean stroke treatment and geometric balance
- restrained accent color for action states and trust cues

## Brand language notes

- Speak in short imperative phrases and declarative statements.
- Use verbs that imply control (`capture`, `route`, `deliver`, `verify`, `ship`).
- Keep technical claims specific and measurable.

## Visual system proposal

- **Primary background:** graphite / near-black canvas
- **Accent color:** cool signal blue (`#6ba6ff`) with secondary whisper-green tint if needed
- **Text system:** high contrast sans-serif with broad tracking, generous whitespace
- **Motion style:** fluid wave fields + soft parallax glow, but subtle and performant
- **UI vocabulary:** cards, chips, grid rhythm, terminal-like command accents

## Landing page direction (for this build)

- One cinematic hero with animated canvas wave layer
- Three-part workflow explanation: Capture → Process → Deliver
- Privacy-first and API-first positioning shown side by side
- Strong CTA blocks for both desktop and daemon audiences
- Crisp FAQ and trust section to reduce adoption friction
